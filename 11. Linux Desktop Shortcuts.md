
#  **What is `linux-desktop-shortcuts`?**

* **Linux** → because it’s related to Linux systems.
* **Desktop** → because `.desktop` files are what Linux desktop environments (GNOME, KDE, XFCE, etc.) use to integrate apps into the application menu, dock, or taskbar.
* **Shortcuts** → because `.desktop` files act like **shortcuts/launchers** for applications (similar to `.lnk` files in Windows).

---

# 1. **VirtualBox Launcher Setup**

1. Edit the file:

```bash
vim /usr/share/applications/virtualbox.desktop
```
> :wq = save file

2. Add the following `.desktop` content:
> Add this line in last line in Desktop Entry  
```ini
StartupWMClass=VirtualBox Machine
```

> Full File Data
```ini
[Desktop Entry]
Name=VirtualBox
GenericName=PC virtualization solution

Type=Application
Exec=VirtualBox %U
TryExec=VirtualBox
Keywords=virtualization;
Keywords[de]=Virtualisierung;
Keywords[ru]=виртуализация;
MimeType=application/x-virtualbox-vbox;application/x-virtualbox-vbox-extpack;application/x-virtualbox-ovf;application/x-virtualbox-ova;
Icon=virtualbox
Categories=System;Emulator;Utility;
Actions=Manager;
Comment=Run several virtual systems on a single host computer
Comment[de]=Mehrere virtuelle Maschinen auf einem einzigen Rechner ausführen
Comment[it]=Esegui più macchine virtuali su un singolo computer
Comment[ko]=여러 가상 시스템을 단일 컴퓨터에서 실행합니다
Comment[pl]=Uruchamianie wielu systemów wirtualnych na jednym komputerze gospodarza
Comment[ru]=Запуск нескольких виртуальных машин на одном компьютере
Comment[sv]=Kör flera virtuella system på en enda värddator
StartupWMClass=VirtualBox Machine

[Desktop Action Manager]
Exec=VirtualBox
Name=Open Oracle VM Manager
Name[de]=Oracle VM Manager öffnen

```

3. Make it executable:

```bash
chmod +x /usr/share/applications/virtualbox.desktop
```

4. Update the desktop database:

```bash
update-desktop-database
```

>  Now VirtualBox will appear in your application menu with the proper icon and name.

# 2. **Burp Suite Launcher Setup**

1. Create/edit the file:

```bash
nano /usr/share/applications/burp.desktop
```

2. Paste the following content:

```ini
[Desktop Entry]
Name=Burp Suite Professional
Comment=Platform for security testing of web applications
Exec=/opt/BurpSuitePro/BurpSuitePro
Icon=/opt/BurpSuitePro/.installation/BurpSuitePro.png
Type=Application
Categories=Security;Development;WebDevelopment;
StartupNotify=true
Terminal=false
StartupWMClass=burp-StartBurp
```

3. Make it executable:

```bash
chmod +x /usr/share/applications/burp.desktop
```

4. Update the desktop database:

```bash
update-desktop-database
```

>  Now Burp Suite will also appear in your application menu.
