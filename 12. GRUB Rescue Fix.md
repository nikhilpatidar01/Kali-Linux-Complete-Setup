
# GRUB Rescue Fix & Dual Boot Stability

## Step 1: Temporary Boot from GRUB Rescue

### Check each partition for `/boot/grub`

```bash
ls (hd1,gpt1)/
ls (hd1,gpt2)/
ls (hd1,gpt3)/
```

👉 Keep checking until you find the partition that contains `/boot` and `/boot/grub`.

### Set the correct partition

```bash
set root=(hd1,gpt6)
```
```bash
set prefix=(hd1,gpt6)/boot/grub
```
```bash
insmod normal
```

```bash
normal
```

⚡ This will boot the system **temporarily**.

---

## Step 2: Permanent Fix via Live USB (Recommended)

### Mount root partition

```bash
sudo mount /dev/sdaX /mnt
```

### Bind mount system directories

```bash
sudo mount --bind /dev /mnt/dev
sudo mount --bind /proc /mnt/proc
sudo mount --bind /sys /mnt/sys
```

### Change root

```bash
sudo chroot /mnt
```

## Reinstall GRUB

```bash
grub-install /dev/sda
```

```bash
update-grub
```

### Exit & reboot

```bash
exit
```

```bash
sudo reboot
```

## Step 3: Fix `/etc/fstab` (UUID Mismatch Issue)

### Check UUIDs

```bash
blkid
```

### Edit fstab

```bash
sudo nano /etc/fstab
```

Example entry:

```
UUID=1234-5678-90AB-CDEF   /   ext4   errors=remount-ro   0   1
```

### Verify configuration

```bash
sudo mount -a
```

👉 If no errors appear, the `fstab` configuration is correct.

---

## Step 4: Windows Settings for Dual Boot Stability

### Disable **Fast Startup**

1. Open: `Control Panel → Power Options`
2. Click: **Choose what the power buttons do**
3. Uncheck: **Turn on fast startup**

### Disable **Hibernate**

```bash
powercfg -h off
```

⚡ Disabling Fast Startup and Hibernate ensures stable dual boot, prevents file corruption, and keeps Linux/Windows file access safe.

---

## ✅ Verification Checklist

* System boots normally without GRUB rescue
* `/boot/grub/` files are accessible
* UUIDs in `/etc/fstab` match `blkid` output
* Windows Fast Startup & Hibernate are disabled
